All simulation knobs live in SimParams, built by train_params. Pass keyword overrides to train_params, then ReadGenerator(db; params).

IgSim.train_params — Function
train_params(; kwargs...) -> SimParams

Package defaults: empirical trim/N/D-inclusion margins, IgM-like gated SHM (shm_igm), MiSeq-like Illumina error (illumina_miseq), and domain-randomized flanks. Use shm_igg for switched memory, or shm / GatedRate to set SHM p and the rate range yourself.

IgSim.SimParams — Type
SimParams

Stochastic knobs for recombination, flanks, and body noise. Parametric over distribution types. Construct with train_params or curriculum helpers easy_params / mid_params / hard_params.

Fields

  • v_trim_5p, v_trim_3p — V end trimming (nt)
  • d_trim_5p, d_trim_3p — D end trimming (nt)
  • j_trim_5p — J 5′ trimming (nt)
  • n1_length, n2_length — N-addition lengths (nt)
  • include_d — Bernoulli (or similar) whether the D segment is included
  • flank_5p, flank_3p — unread flank lengths (often DomainFlankMix)
  • body_error_rate, indel_rate — per-read SHM / indel rates (often GatedRate)
  • illumina_error — always-on instrument substitutions (IlluminaError)
  • min_length, max_length — accepted assembled length (nt)
  • max_retries — recombination attempts before error

IgSim.DomainFlankMix — Type

Two-component flank-length mixture for unread 5′/3′ contexts.

With probability p_short, sample length from short; otherwise from long. Used as the default for flank_5p / flank_3p in train_params.

source
IgSim.GatedRate — Type
GatedRate(p, rate)

Two-level body-noise knob for body_error_rate / indel_rate:

  1. With probability p, noise occurs at all.
  2. Conditional on that, the per-base rate is drawn from rate.

Otherwise the sampled rate is 0 (clean / unmutated read).

source
IgSim.shm — Function
shm(p, lo, hi) = GatedRate(p, Uniform(lo, hi))

Convenience for a zero-inflated Uniform SHM prior. Equivalent to constructing GatedRate yourself; lo == hi uses Dirac(lo) instead of Uniform.

  • p — fraction of reads that receive any SHM (the rest have rate 0)
  • lo, hi — per-base substitution rate on the VDJ body when SHM is on
source
IgSim.shm_none — Function
shm_none() = GatedRate(0.0, Dirac(0.0))

Unmutated / naive IgM: no substitutions.

source
IgSim.shm_igm — Function
shm_igm() = GatedRate(0.40, Uniform(0.005, 0.07))

Typical IgM-sorted repertoire: ~40% of reads with biological SHM, per-base rate Uniform(0.5%, 7%) when on (library-wide mean ≈ 1.5%). Single-mismatch noise is left to the Illumina layer.

source
IgSim.shm_igg — Function
shm_igg() = GatedRate(0.97, Uniform(0.015, 0.13))

Switched / memory IgG: ~97% mutated, per-base rate Uniform(1.5%, 13%) when on (library-wide mean ≈ 7%).

source
IgSim.IlluminaError — Type
IlluminaError(p5, p3 = p5)

Always-on Illumina substitutions on the VDJ body after SHM. Rate ramps linearly from p5 at the 5′ body nucleotide to p3 at the 3′ body nucleotide. Pass a single value for a uniform rate (the merged paired-end case). Flanks are skipped — they are already random DNA.

Typical Q30 ≈ 0.001. Illumina indels are omitted (orders of magnitude rarer than substitutions). Use illumina_miseq / illumina_none.

source
IgSim.illumina_none — Function

No instrument substitutions: IlluminaError(0.0).

source
IgSim.illumina_miseq — Function
illumina_miseq() = IlluminaError(0.001)

Merged MiSeq paired-end, uniform ~Q30 (0.1%) on the VDJ body. Overlap merge (FLASH/pRESTO-style, keep higher-Q base) cancels the single-end 3′ decay, so this is not a 5′→3′ ramp. For unmerged single-end use IlluminaError(0.001, 0.004).

Flanks use DomainFlankMix: with probability p_short sample from short, otherwise from long.

A read is labeled no-D only if include_d skips the segment or exonuclease leaves zero D nucleotides. Any remnant of 1 nt or more keeps the originally sampled D label. D 5′/3′ deletions are Geometric (mean ≈ 4 nt, unbounded tail) — the same process on every D gene, then clamped by available length. Short Ds are fully eaten more often as a consequence, not via a special case. This is causal gold, not an IgBLAST minimum consecutive-match cutoff. The mean is set so IgBLAST / SwiftIG empty-d_call rates on sim land near the same tools on real reads; gold emptiness stays higher than either caller reports.

Error model

SHM and Illumina both apply to the VDJ body (not flanks). SHM first, then Illumina. Presets are zero-arg aliases — the implementation is the GatedRate / IlluminaError on the right.

SHM is GatedRate: with probability p draw a per-base rate from rate, otherwise 0. Each body base then substitutes independently.

AliasImplementationTypical use
shm_noneGatedRate(0.0, Dirac(0.0))naive / unmutated IgM
shm_igmGatedRate(0.40, Uniform(0.005, 0.07))IgM-sorted library (default)
shm_iggGatedRate(0.97, Uniform(0.015, 0.13))switched memory IgG
shm (p, lo, hi)GatedRate(p, Uniform(lo, hi))custom mix

This is a training prior (naive peak + mutated clones), not a fit to one repertoire. Uniform over mutation depth is a flat prior; for a heavy tail use GatedRate(p, LogNormal(μ, σ)). No AID hotspot / CDR targeting.

Illumina (IlluminaError) is always-on and applied after SHM. Default IlluminaError(0.001) is uniform ~Q30 on a merged paired-end contig (overlap keeps the higher-Q base, so single-mate errors are usually dropped). For unmerged single-end use a ramp, e.g. IlluminaError(0.001, 0.004). Disable with IlluminaError(0.0) / illumina_none. Substitutions only.

Replace either flank with a single DiscreteUniform (or any sampleable) if you want a simpler length model.
